Built a functional shell from the ground up, which involved:

- Parsing complex command lines with pipes , redirections and variables.
- Managing processes, inter-process communication and low-level system calls.
- Remaking various GNU Core Utils commands.
- Extensive debugging and handling of memory management.

This project was a deep dive into the core of Unix systems, solidifying my skills in leadership, systems programming, collaborative problem-solving, and software design.
It was a challenging and incredibly rewarding experience.
